## GCD and LCM Calculation Script
This script calculates the GCD and LCM of two numbers input by the user, and also calculates the GCD of two other numbers.

- GCD (Greatest Common Divisor): The largest number that divides both numbers without leaving a remainder.
- LCM (Least Common Multiple): The smallest number that is a multiple of both numbers.
