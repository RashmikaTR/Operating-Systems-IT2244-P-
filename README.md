## 📅 Date
07/04/2025 
## This repository contains a series of shell scripting exercises for the Operating Systems IT2244 (P) module.

## Descriptions
## Script 01: Multiplication Table Using For Loop
This script prints the multiplication table for even numbers between 2 and 50.

## Script 02: Star Pattern Using For Loops
This script creates a pyramid-like pattern with stars (*), and then inversely prints it. The first half creates an increasing star pattern, and the second half creates a decreasing star pattern.

## Script 03: Square Border with Stars
This script prints a 5x5 square with stars (*) along the border.
